01 · Roll Link

A link that flips to reveal another link copy in a different style

## how it actually works

The mask: sets "window" for the visual, clips its overflowing content with overflow:hidden;

the track: holds two link labels splitting the track 50/50 because the track moves up 50% to reveal the link hidden below

the muting: the selector says: "Inside a navigation menu that has a hovered or focused link, select every other link that isn't currently hovered or focused."
